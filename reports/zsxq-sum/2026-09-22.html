1

刘煜辉：这是市场第一次为"消费端 Agent 的算力增量"定价

Muse 证明了 「够用的模型 + 海量用户场景 + 可落地的 Agent」能创造巨大算力增量。他强调—— 这个增量不在 GPU，而在 CPU + 虚拟机 + 存储 + 网络 + 安全的整条基础设施链条。

2

广发电子：美股 CPU 链大涨，A 股映射名单出炉

Muse 引爆个人消费 Agent 需求，Agent 对 CPU 用量显著提升。建议关注 澜起科技、聚辰股份、广合科技、海光信息、通富微电。

3

东吴电子（陈海进）：杰华特——CPU 电源链直接受益，持续强 Call

Agent 执行链路延长后，CPU 需承担虚拟机、浏览器、多任务调度； Intel 表示当前 CPU 产能仅能满足约一半模型公司客户。杰华特已形成 「多相控制器 + DrMOS + E-fuse + POL」完整服务器供电方案，与 Intel 持续推进合作。

4

404K 科技早报定性：需求向外扩散

今日早报标题即为「智能体拉动 CPU 与网络，光互联加快系统集成」——供给瓶颈叙事正从单点 GPU 转向整条系统集成。

关键推论：如果 Agent 的"执行链路"继续延长，CPU 将成为继 HBM、电源、钻针之后下一个低弹性瓶颈； 而 Intel 自己承认产能只能满足一半客户，意味着服务器 CPU 有望迎来需求与估值双重修复。
