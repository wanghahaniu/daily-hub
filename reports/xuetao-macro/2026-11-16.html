美国算力，就是中国稀土

新增 报告日期 2026-11-15 公众号发布 2026-11-16 07:53 腾讯新闻（来源：雪涛宏观笔记） 东方财富财富号（全文） 网易号「券商研报精选」 科技专题 · 财政与产业融资
一句话结论
AI 时代的大国竞争已把算力变成与稀土同构的「关键供给」——国家一旦认定某项产业能力不能随商业周期收缩，维持领先就必须承担超出常规商业考量的成本。中选「蓝潮」的产业含义，是把算力融资从「私人资本自发建设」推向「私人回报 + 国家安全 + 国内利益分配」三方共同决定；而美国 AI 产业的约束正从技术突破转向资产负债表与融资能力，因此作者提出借鉴 FHLB 设立「联邦科技银行」的构想。
核心观点
  1. 「碳基时代的稀土」与「硅基时代的算力」是同构的。逻辑是：让其他国家围绕本国掌握的关键供给组织生产。维持这种领先需要承担超出常规商业考量的成本——「这种成本既可能体现为生态环境的代价，也可能体现为企业利润的让渡」。稀土承担生态代价，算力则要求企业让渡利润。
  2. 中选蓝潮改变了 AI 产业的融资决策主体。报告判断，此次中期选举的产业意义在于推动算力融资从「私人资本自发建设」，转向由「私人回报、国家安全与国内利益分配」共同决定。并给出政治惯性外推：民主党「蓝潮」可能在未来两个选举窗口继续扩大，甚至形成参议院 60 席的相对多数乃至 67 席的绝对多数；在这一情景下，共和党重新形成有效抗衡的时间窗口「可能要等到 2030 年乃至 2032 年」。
  3. 管制正从 GPU 本身扩展到围绕 GPU 的技术生态。报告点名四项法案：AI OVERWATCH Act、MATCH Act、Chip Security Act、Remote Access Security Act，其中前三项已打包纳入 2027 财年美国《国防授权法案》（NDAA）的参议院修正案包。这些法案「主要针对过去几年 GPU 出口管制实践中暴露的漏洞」，「美国试图控制的，已不只是 GPU 本身，而是围绕 GPU 形成的技术生态及其使用方式」，控制手段从商品出口管制蔓延至设备、供应链、最终用户和云端服务。报告同时指出，特朗普可行使否决权，但在当前政治氛围下「可能面临较高的政治成本」。
  4. 成本分担原则的变化比成本规模更重要。若上述法案通过并叠加《两党美国可负担性与就业法案》（BAAJA）推进，后者一方面加快能源许可，另一方面要求数据中心承担电网成本，未来十年成本增加约 550 亿美元。报告强调：「企业成本增加的规模并非分析重点；更值得关注的是成本分担原则的变化」——要求企业承担更多基础设施成本，实质是在调整企业与居民之间的利益分配。投资含义是：战略重要性不等于每个数据中心都实质产生公共利益，但每个项目都可能被拿到公共利益的透镜下审视——组件来自哪里、现金流由谁提供、客户是谁、算力最终用于何处。在这一框架下，Anthropic 所体现的「扎根美国、服务美国」定位「使其更易获得政治认同，并带来一定的『政治溢价』」。
  5. 核心矛盾：国家想要的投资规模，超出私人资本愿意提供的资源。通用模型能力已提升至国家无法忽视的程度，随着模型参与前沿科研、工业设计乃至军事任务，国家对安全与控制权的关注还会增强。市场曾把英伟达比作全球科技企业的「央行」（循环融资、担保贷款、股权投资），但这种依托产业上游主导地位的安排，「如果未来投资决策需要更多考虑政治因素……可能难以持续支撑国家希望维持的投资规模」。
  6. 制度构想：借鉴联邦住房贷款银行体系（FHLB）设立「联邦科技银行」。可从三方面理解：①经济必要性上升——AI 正把科技行业从「轻资产、高利润率、高现金流」推向「重资本开支、长投资回收期、高度依赖债务融资」；②国家主导能力提升——FHLB 通过合格抵押品、会员制和低成本债券融资，把分散金融资产转化为「准主权信用」特征的融资能力；③路径上「可能先出现『功能上的联邦科技银行』，再考虑是否建立『法律上的』」，因为照搬 FHLB、建立全国性 GSE 需国会立法，分立政府下阻力较大。报告给出三种制度路径（按落地难度由低到高，原文以图表列示，转载文本未含表体），并指出模式 A 已具备一定政策基础：美国能源部以 Office of Energy Dominance Financing 名义延续原贷款项目办公室（LPO）体系，累计已发放贷款及提供贷款担保约 1400 亿美元，范围已扩展至电网和关键矿产。
逻辑链
中选「蓝潮」扩大 → 政治成为影响企业发展空间的重要变量（科技界代表人物近一周遭遇政治压力） → 算力从商业产品升格为「关键供给」 → 管制从 GPU 扩展至设备、供应链、最终用户、云端服务（四项法案 + NDAA 修正案包） → 企业承担更多非商业成本（BAAJA 要求数据中心承担电网成本，十年约 550 亿美元） → 国家希望维持的投资规模超出私人资本基于商业回报的意愿 → 单纯依靠企业间融资安排（英伟达「央行」角色）难以为继 → 需要准主权信用的制度安排（联邦科技银行） → 融资可得性改善、期限延长，但全行业利率压降有限

原文直述 铜 / 基本金属：全文未提及铜及任何基本金属的供需、库存或价格。文中「稀土」是战略隐喻而非商品观点——用于说明「关键供给可转化为国家权力」，原文未对稀土价格、出口量或配额作出任何判断。无直接关联。

延伸推断 若 BAAJA 的「数据中心承担电网成本」落地，等于把电网扩容的资本开支内部化到项目方，理论上对变压器、开关、电缆等电力设备的实物需求形成支撑，铜作为配电侧主要导电材料受益。但报告明确「企业成本增加的规模并非分析重点」，且 550 亿美元是十年累计的成本增量，摊到年度的设备端铜耗增量有限，不足以构成商品级别的需求冲击。此为本文推演，非原作者观点。

延伸推断 四项法案若把管制延伸至「云端服务」，则海外客户获取美国算力的合规成本上升、灰色渠道收窄，可能推高非美地区的算力租赁价格，进而影响当地数据中心的建设节奏与相关电力设备采购。这条链条原文未展开，属本文补白，非原作者观点，不应作为交易依据。
